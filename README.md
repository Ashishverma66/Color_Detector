# 🎨 Color Detector & Image Manipulation (OpenCV)

## 📌 Project Description

This project demonstrates basic image processing and real-time computer vision using **Python** and **OpenCV**. It includes:

- **Basic Image Manipulation:**
  - Convert an image to grayscale
  - Apply Gaussian blur
  - Detect edges using Canny edge detection

- **Color Detector using Webcam:**
  - Real-time webcam feed
  - Click on any point to get the BGR color values
  - Dynamically displays selected color and its values
